Separador en forma de ola entre dos secciones de color distinto: el guiño surf que da ritmo al scroll.

- `from` = color de la sección de arriba, `to` = el de abajo; `back` tiñe la ola trasera (por defecto el mismo `to` al 55 %).
- Úsala como mucho 2–3 veces en la home (hero → prueba social, servicios → misión, antes del footer `wave-indigo`). Entre secciones del mismo color, no.
- `flip` invierte la dirección para alternar el oleaje. Es decorativa (`aria-hidden`).
